# ヤマト運賃情報取得ツール

Web請求書提供サービスから**部門名1・部門名2**を含む全データを自動取得してExcel出力します。

---

## ファイル構成

```
yamato/
├── config.py              # ← ID/PW設定（要編集）
├── yamato_scraper.py      # スクレイピングロジック
├── yamato_page.py         # Streamlit UI
└── requirements_yamato.txt
```

---

## セットアップ手順

### 1. パッケージインストール
```bash
pip install -r requirements_yamato.txt
```

### 2. config.py を編集
```python
YAMATO_CONFIG = {
    "login_id": "実際のID",      # ← 変更
    "password": "実際のPW",      # ← 変更
    ...
}
```

### 3. 起動方法

**単体ページとして起動**
```bash
streamlit run yamato_page.py
```

**既存のStreamlitアプリに組み込む場合**
```
your_app/
├── app.py
├── pages/
│   └── ヤマト運賃取得.py  ← yamato_page.py をコピー
├── yamato_scraper.py      ← ルートに配置
└── config.py              ← ルートに配置
```

---

## 使い方

1. ブラウザで Streamlit を開く
2. 取得期間（受付日）を指定（最大31日）
3. 「▶ 取得開始」ボタンを押す
4. 完了後「📥 Excelをダウンロード」で保存

---

## 出力Excelの列構成

| 列 | 内容 |
|----|------|
| 受付日 | 受付日 |
| 原票No | ヤマト原票番号 |
| 商品区分 | 宅急便発払など |
| サイズ | 100/120など |
| 個数 | 個数 |
| 都道府県 | 配達先都道府県 |
| 市区町村 | 配達先市区町村 |
| **部門名1** | ★詳細画面から取得 |
| **部門名2** | ★詳細画面から取得 |
| 運賃 | 運賃（円） |
| 立替金 | 立替金（円） |
| 保険料 | 保険料（円） |
| 運賃等合計 | 合計（税別、円） |

---

## 注意事項

- `config.py` は `.gitignore` に追加してください（ID/PWが含まれます）
- サーバー負荷軽減のため1件2秒の待機を入れています
- セッションタイムアウト（長時間処理）の場合は期間を分割してください
- 200件で約7〜10分が目安です
